## 📌 Project Overview
This project delivers a comprehensive exploratory data analysis (EDA) and machine learning pipeline to analyze high school student performance based on demographic, social, familial, and academic factors. By analyzing historical grade trajectories and behavioral drivers, the model predicts final student outcomes (`G3`) and identifies students at risk of academic failure.

## 🔗 Dataset Information
* **Source:** https://www.kaggle.com/datasets/whenamancodes/student-performance?resource=download
* **Domain:** Education / Academic Analytics
* **Attributes:** 33 features per student (study habits, parental education, alcohol consumption, absences, past performance `G1` and `G2`, and final score `G3`).

## 🛠️ Technologies & Libraries Used
* **Programming Language:** Python 3.9+
* **Data Manipulation:** pandas, numpy
* **Data Visualization:** matplotlib, seaborn
* **Machine Learning & Preprocessing:** scikit-learn (Random Forest Classifier/Regressor, Ridge Regression, StandardScaler, OneHotEncoder)
